Install Huddle now

You can install the beta right away — no app store required.

Open Huddle

On iPhone

  1. Open huddleza.netlify.app in Safari
  2. Tap the Share button (square with arrow)
  3. Scroll down and tap "Add to Home Screen"
  4. Name it "Huddle" and tap Add

On Android

  1. Open huddleza.netlify.app in Chrome
  2. Wait a few seconds
  3. Tap "Install app" when it appears
  4. Or: tap the ⋮ menu → Install app
